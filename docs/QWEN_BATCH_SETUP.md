# Qwen 共享模型批量推理安装

多条兼容文本可以共用模型和音色特征，减少重复加载。首次安装需要下载独立运行环境和配套模型，并预留数 GB 的磁盘空间。

## 一键安装

1. 在「设置 → 模型」下载或导入 Qwen3-TTS 0.6B / 1.7B Base GGUF 模型。
2. 进入「设置 → 批量性能 → Qwen 共享模型批量推理」。
3. 在「自动关联模型」选择刚添加的 Base 模型。
4. 「运行环境来源」选择「国内加速（推荐）」，「模型下载来源」选择「ModelScope 魔搭（国内）」。
5. NVIDIA 显卡选择「NVIDIA CUDA」；使用处理器推理时选择「CPU」。
6. 点击「一键安装并关联」，等待状态显示批量后端已就绪。

安装器会检测并复用已有环境和完整文件。无需为本程序额外安装 Python；运行环境保存在设置页显示的数据目录中。

## 下载慢或中断

- 国内加速覆盖 Python、PyTorch 和 Qwen SDK，依赖源失败后会尝试备用来源。
- 模型可选择魔搭、HF 镜像或 Hugging Face。
- 点击「暂停」，等到状态变为「已暂停」后更换来源，再点击「继续安装并关联」。支持续传的文件会保留进度。
- 所有模型文件均进行大小和 SHA-256 校验。校验失败时重新下载对应文件，避免使用不完整模型。
- 下载与安装的详细记录保存在数据目录的 `logs/qwen-batch-install.log`。

## 常见情况

- 没有可关联模型：先添加受支持的 Qwen3-TTS Base GGUF；运行环境也可单独提前下载。
- 提示本地服务是旧版本：退出旧版窗口和独立启动的旧服务，再打开新版程序。
- CUDA 不可用：检查 NVIDIA 驱动；也可选择 CPU 环境重新安装。
- 文件就绪但正在等待：当前生成结束后自动关联，已有下载会保留。

首次生成仍需要加载模型。批量后端不可用或文本不符合合批条件时，自动模式会使用原生推理。
