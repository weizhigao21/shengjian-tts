# 音频编辑 · v0.7.32

从「语音创作 → 音频编辑」进入。已有生成记录也可以点击「编辑音频」，或在设置的音频列表中右键选择「在音频编辑中打开」。文章与对话保留原来的编辑和生成流程。

## 第一版功能

| 操作 | 行为 |
| --- | --- |
| 导入 | PCM WAV，单声道或双声道，8–192 kHz，8 / 16 / 24 / 32 位；最多 30 分钟、512 MB。导入时复制原音频，后续处理不改源文件。 |
| 选区 | 在波形上拖动，或输入起止秒数；全选处理保留全部采样。 |
| 基础调整 | 保留选区、调整音量、淡入淡出；每次保存成新版本。发生削波时显示提示。 |
| 拼接 | 把另一个 WAV 接在选区末尾。两个文件需具有相同的采样率、声道和位深。 |
| Vevo2 换声 | 原音频选区 + 目标音色参考 WAV；使用 `vc / style_preserved_vc` 路线。 |
| Vevo2 台词修改 | 音频选区 + 目标文本；使用 `s2s / editing` 路线。可沿用选区音色，也可指定另一份参考 WAV。 |
| 试听与历史 | 试听选区或原音频，播放结束停止；点击历史版本或返回上个版本，再从该版本继续编辑。 |
| 保存与导出 | 保存名称和原文 / 目标文本；导出当前完整版本为 WAV。退出前也会尝试保存当前名称与台词。 |

基础调整不需要模型、GPU 或 FFmpeg。第一版不解码 MP3、压缩或浮点 WAV，也不提供自动转写、多轨混音、自动局部回填和接缝修复。

## 使用 Vevo2

1. 在设置中选择 audio.cpp 引擎（适配接口依据 v0.9.1）。
2. 下载扫描目录中的 Vevo2 GGUF，或在编辑页 / 模型设置页导入本地 Vevo2 GGUF。引擎包与权重分别安装。
3. 导入音频，选择一个短片段。第一版每次 AI 处理最多 60 秒，建议先用几秒钟试听。
4. 换声时选择 1–60 秒的目标参考 WAV。台词修改可选择「沿用原音频音色」，填写选区对应原文与修改后的文本。
5. 处理完成后对比试听。结果是选区重新合成的独立音频，需要保留前后段时可先裁剪，再拼接。

AI 处理与文章 / 对话推理互斥。配音正在生成时，编辑请求会提示等待；音频 AI 处理期间，配音任务保留在队列中。编辑结束或取消会释放 Vevo2 进程。随机种子在提交时固定并保存到版本参数，便于追溯。

Vevo2 的声音、时长和韵律可能随重新合成变化，不保证未修改部分逐采样一致。接口路线依据 [audio.cpp Vevo2 文档](https://github.com/0xShug0/audio.cpp/blob/v0.9.1/docs/models/vevo2.md)与[服务请求协议](https://github.com/0xShug0/audio.cpp/blob/v0.9.1/app/server/README.md)。官方权重采用 [CC-BY-NC-ND-4.0](https://huggingface.co/RMSnow/Vevo2)，独立于声笺应用许可证，发行包不包含权重。

## 数据与模块

编辑项目使用单独的 `data/audio-editor/audio-edits.sqlite3`，原音频与完成版本使用同一目录内的 UUID 文件名。一个项目具有稳定片段 ID，版本记录含来源版本、操作、选区、参数、时间、结果或错误。名称只负责显示，悬停音频说明或历史记录可查看 ID。

原始导入版本保持不变。恢复旧版本只切换当前来源，不删除较新的结果；下次处理创建分支。服务重启时把未完成的处理标为失败，完成版本保留。

名称与台词保存复用按项目和修订号排队的草稿机制；断线待存内容写入 `data/pending-audio-edits.json`，重新连接后重试。处理期间每 1.2 秒刷新进度，空闲时降低为每 10 秒刷新，隐藏页面停止查询。

- `audio_editing/pcm.py`：分块校验和 PCM 操作，保持原采样率、声道与位深。
- `audio_editing/store.py`：独立 SQLite 项目与版本记录。
- `audio_editing/service.py`：导入、任务、取消、引擎互斥和生命周期。
- `audio_editing/vevo2.py`：专用 `vc / s2s` 请求，复用原生服务启动与路径兼容处理。
- `audio_editing/schemas.py` 与 `http_api/audio_editing.py`：字段校验和本机 API。
- `desktop/layout/audio_editing.py`：页面装配；`controllers/audio_editing.py`：请求、版本选择与播放；`components/audio_selection.py`：波形选区。

验证覆盖真实 WAV 操作、API / 数据恢复、取消互斥、Qt 页面与请求协议。开发环境尚未安装 Vevo2 权重，因此模型输出质量及显存表现仍需实际模型验证。
