# 对话模式方案

状态：交互方案已确认方向，功能尚未实现。本轮先整理代码结构。

## 目标

在「语音创作」顶部增加「文本 / 对话」切换。文本模式继续编辑长文；对话模式按对白逐条选择声音预设、生成、试听和重新生成。一个作品包含多条对白，生成时追加到作品的历史记录。

## 对话编辑区

```text
语音创作                            [文本] [对话]

[御姐 ▾]                         ✓ 已生成 · 耗时 8.2 秒
冬，裹着白棉袄悄然而至。
                                  试听 · 重新生成

[萝莉 ▾]                         待生成
你看，外面下雪了！

＋ 添加对白
```

沿用 UI_STYLE.md：白底、细分隔线、小音色标签；选中时浅灰背景。状态保持可见，行操作在选中或悬停时显示。右侧显示选中对白的模型与参数，底部复用播放器。

## 已确定的功能方向

| 功能 | 行为 |
| --- | --- |
| 音色选择 | 每条直接选择已有声音预设，无需先配置角色 |
| `@` 输入 | 对白开头输入 `@` 弹出预设列表；选中后形成音色标签，空格后输入正文 |
| 单条处理 | 独立生成、试听、查看失败原因和重新生成 |
| 批量生成 | 「生成待处理对白」处理新增、修改和失败的条目 |
| 完成状态 | 显示待生成、排队中、生成中、已生成、已修改、失败、已取消 |
| 历史版本 | 重新生成成功后，新版成为当前音频，旧版仍可在音频管理中查看 |
| 播放 | 普通播放按钮试听当前条；「播放整段对话」明确进入连续播放 |
| 排列与停顿 | 调整对白顺序，设置相邻条目之间的停顿 |
| 导出 | 导出当前条，或按对白顺序拼接整段音频 |
| 持久化 | 保存作品模式、条目顺序、文本、声音和生成记录 |

## 输入与编辑规则

1. 第一版一条对白使用一个音色；正文自动折行仍属于这一条。
2. `@` 仅在条目开头作为音色入口；正文中的邮箱、普通 `@` 字符按文字处理。
3. 标签绑定预设 ID，名称只负责显示。现有带空格的预设名不通过空格猜测；重名时同时显示模型。
4. 未指定音色的条目使用作品默认声音。生成时保存实际使用的配置快照。
5. 调整选中条目的参数只影响该条；修改声音库预设需要显式保存。
6. 修改文字、声音或生成参数后标记「已修改」，保留上一版音频用于比较；只改顺序或停顿不重新推理。
7. 插入、删除、排序后，条目与音频保持对应，通过稳定条目 ID 关联，避免用显示行号作为身份。
8. 建议 Enter 新建下一条，Shift+Enter 在当前条换行；具体快捷键可在实现前调整。

## 生成与播放

- 作品共享同一任务，单条/批量生成追加生成记录。每条提交自己的模型、音色、参数快照和来源预设。
- 「重新生成」执行新一轮推理；固定种子保持用户设定，随机模式生成新种子。
- 单条失败不取消其他可生成条目。错误显示具体条目、阶段、原因及建议。
- 同一模型尽量复用已加载权重；不同模型先顺序处理，播放及导出始终按对白顺序。
- 批量执行固定本次提交快照，执行期间的编辑标记为下一轮待生成内容。
- 拼接导出时统一采样率和声道，并加入设定停顿。存在缺失或过期音频时明确列出对应条目，用户选择处理方式后再导出。
- 双语工作流继续使用现有记录与临时音频交付规则，对话作品使用桌面作品的持久音频规则。

## 实施顺序与验收

1. **代码整理**：拆分窗口、设置、API，提取生成准备逻辑；原功能、接口、数据和打包回归通过。
2. **对白编辑**：模式切换、条目增删、`@` 预设选择、保存与重开；先不引入复杂角色管理。
3. **生成记录**：不同预设逐条生成、只生成待处理条目、单条重生成、修改状态、历史音频对应。
4. **顺序播放与导出**：显式整段播放、停顿、混合采样率拼接、顺序调整。

重点验收：带空格/重名预设；预设改名或删除；固定/随机种子；失败后重试；修改期间生成完成；排序后音频对应；旧作品重开；普通试听结束停止；双语工作流不创建桌面作品。

第一版暂不加入一句话内多次 `@` 切换、独立角色管理页及跨模型并行加载。这些功能留到基础交互稳定后评估。
