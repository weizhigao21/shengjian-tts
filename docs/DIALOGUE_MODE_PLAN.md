# 对话模式方案

状态：v0.7.24 已实现独立文章 / 对话任务、固定任务类型、每框参数与音频范围、预设选择、单条生成与状态。后续增加顺序调整、显式整段播放和拼接导出。

## 当前功能

- 「语音创作」「新建配音」进入类型选择页，选择后创建任务，类型固定。文章沿用整篇文本、字幕编辑和右侧生成按钮；对话按条编辑。名称前的「返回」保存当前任务并回到入口，再选择类型会新建任务。
- 对白开头输入 `@`，通过中文搜索、鼠标或键盘选择声音预设。选中后显示音色图标标签，正文不包含标记；点击标签可以换音色。
- Enter 新增下一条，Shift+Enter 在当前条换行。未指定预设时使用右侧当前模型和参数。
- 每条提供生成、试听、重新生成和移除按钮，显示状态，生成耗时放在悬停提示和音频列表；正文或声音发生变化后标记「已修改」。
- 每框显示稳定短 ID，点击框后，右侧参数及底部生成列表、播放、导出只对应它；框的全部历史音频保留完整 ID 和生成时音色快照。
- 最近作品用文章页 / 对话气泡图标区分类型，只显示名称；时间保留在记录和悬停提示。生成音频管理分为文章与对话分类，「全部删除」只删除当前列表。
- 整批与单条生成都追加到同一作品。重新生成跳过缓存执行新推理，保留旧音频，普通试听结束后停止。
- 预设按 ID 绑定，支持改名及重名。预设被删除时明确提示，不自动改用其他声音。未完成的 `@` 选择阻止生成；字面行首 `@` 使用 `@@`。
- 文本框随内容增高，长内容可以滚动。音色列表悬停选中，省略的名称通过提示显示完整内容。

## 数据与模块

| 内容 | 保存方式 |
| --- | --- |
| 编辑器 | 作品 `editor_state`：模式、文章及标签、按顺序排列的对白条目 |
| 对白条目 | 稳定 ID、正文、声音预设 ID、模型配置 ID 和局部参数 |
| 生成记录 | 片段 `source_id`、`source_revision`、实际声音与模型参数快照 |
| 历史音频 | 复用原生成记录和音频管理；移除对白不删除历史文件 |

旧作品按文章打开，原标签保持兼容。数据库只增加字段，迁移前自动备份；双语工作流沿用只记录与临时音频交付规则。

页面装配放在 `desktop/layout/creation.py`；编辑组件放在 `desktop/components/dialogue.py`；交互和保存放在 `desktop/controllers/creation.py`；版本计算放在 `services/dialogue.py`。生成沿用原 HTTP 接口、队列和推理适配，具体结构见 [代码架构](ARCHITECTURE.md)。

## 后续计划

1. 「生成待处理对白」只处理新增、修改和失败条目，保留当前整批生成入口。
2. 调整对白顺序和停顿；仅更改顺序或停顿时不重新推理。
3. 增加明确的「播放整段对话」按钮，普通试听继续只播放单条。
4. 按对白顺序拼接导出，统一采样率和声道；缺失音频明确列出条目。
5. 评估一句话内多次切换音色及跨模型并行。

验收重点：文本完整显示、悬停与键盘选择、重名和改名预设、保存重开、条目和音频对应、固定种子重新推理、旧数据库迁移及工作流兼容。
