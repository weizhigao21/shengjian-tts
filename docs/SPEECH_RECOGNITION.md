# 语音识别 · v0.7.39

从「语音创作 → 语音识别」进入。把音频拖到页面上，或点击「导入音频」选择文件，拖入后立即显示文件名和「导入中」，无需等待解码或识别完成；识别完成后点击左侧任意一行即可播放对应片段。文章与对话的原有流程不受影响。

第一版只读取音频，不修改用户的原文件；PCM WAV 导入时复制到数据目录，其他编码通过随包提供的 Qt / FFmpeg 在独立进程转换为 PCM WAV；采样率和声道保持原音频解码后的值，无需另外安装 soundfile 或 FFmpeg 命令。

## 第一版功能

| 操作 | 行为 |
| --- | --- |
| 导入 | WAV / FLAC / MP3 / M4A / AAC / OGG / OPUS / WMA / AIFF / AIF；拖放或选择文件，PCM WAV 保留副本，其他编码转换为私有 PCM WAV，原文件不变。 |
| 识别 | 使用引擎内的 ASR 模型转写文字，中文结果自动补标点；可选择语言或自动判断。 |
| 分行 | 按标点与停顿切分，每行不超过 24 字或 8 秒，空格分词的语言（英语等）放宽到 42 字；句末标点必定换行，从句标点只在行较长时换行。 |
| 点行播放 | 点击某一行播放该行的时间范围；再次点击同一行停止，勾选「连续播放」可依次播完。 |
| 精确时间 | 安装了强制对齐器时使用引擎给出的词级时间戳；未安装时按标点估算每行时间，并在结果中提示。 |
| 导出 | 导出 SRT 或 TXT 字幕，或复制全文。 |
| 管理 | 重试、取消、删除记录；重命名只影响显示名称。最近作品统一展示文章、对话、音频编辑与识别任务，用不同图标区分，点击回到对应记录。 |

## 需要哪些模型

识别与对齐都走程序内置的统一引擎，跟随「设置 → 推理引擎」中选择的计算设备，不需要另装 Python 或外部框架。

| 用途 | 模型 | 说明 |
| --- | --- | --- |
| 文字转写 | Qwen3-ASR 0.6B Q8_0 | 必需。点击识别模型旁的「下载 / 管理」，定位到对应模型列表；下载或导入后自动出现在下拉框中。 |
| 词级时间 | Qwen3 强制对齐器 0.6B Q8_0 | 可选。点击时间对齐旁的「下载 / 管理」，定位到对应模型列表；安装后每行时间精确到词，未安装时按标点估算。 |

下载复用「设置 → 模型」中的下载器，可选择精度与下载来源、查看进度和暂停续传；点击入口不会直接下载大文件。若列表为空，请先安装或更新统一引擎，再点击「扫描支持模型」。

识别模型按引擎的 `model_specs` 任务声明自动登记为识别模型，只出现在识别模式，不会成为可选音色，也不会创建声音预设。

## 时间与分行

引擎给出的词级结果带有帧号与秒字段。秒字段按输入采样率换算，实测 `48 kHz` 输入时会偏小为真实值的三分之一，因此程序统一使用帧号除以 `16 kHz` 还原时间；只有在没有帧号时才回退到秒字段。

对齐器返回的词只包含字符，句读标点会被丢弃，中文和英文都一样（英文的 `position.` 同样只回来 `position`）。程序先把标点贴回其前一个字符，再据此分行，避免长句被长度上限硬切。小数的句点单独判断：前后都是数字时不作为句末标点，`3.5` 不会被拆到两行。

## 数据与模块

识别记录保存在 `data/recognition/recognition.sqlite3`，音频副本使用同目录的 UUID 文件名。重启服务时，上次未完成的任务会标记为中断，音频副本保留，可重新识别。

最近作品从各自数据库只读汇总名称与状态，不合并数据库，也不复制音频。导入中的临时记录在成功后替换为正式任务，失败后移除并恢复原任务；导入期间切到其他记录，完成时只更新列表。

识别与音频编辑共用管理器的推理互斥：配音正在生成时，识别会提示等待；识别期间配音任务留在队列中。识别结束时释放引擎进程。识别与 AI 音频编辑也执行双向互斥检查；普通 WAV 裁剪可独立运行。忙碌时拒绝导入不会创建记录；重新识别失败时保留已有结果。

- `speech_recognition/lines.py`：时间戳换算、标点回填与分行规则。
- `speech_recognition/audio_import.py` 与 `decode_worker.py`：音频副本准备、独立 Qt 解码及坏文件清理，HTTP 服务不导入 Qt。
- `speech_recognition/runner.py`：同一引擎进程内的识别与对齐请求，含中文路径兼容。
- `speech_recognition/service.py`：模型选择、音频导入、执行、取消与重试。
- `speech_recognition/store.py`：独立 SQLite 会话存储。
- `speech_recognition/schemas.py` 与 `http_api/recognition.py`：字段校验与本机 API。
- `desktop/layout/recognition.py`：页面装配与页内拖放；`controllers/recognition.py`：请求、点行播放与导出。

## 验证范围

v0.7.39 新增回归覆盖四种任务在启动前读取、侧栏跳转、即时导入名称、失败恢复和异步切换；模拟下载验证对齐模型经过现有校验流程后成为可选模型。

补充回归覆盖并发提交、启动失败回滚、双向互斥、重复重新识别，以及后台刷新时的连续播放、选中行、名称与语言编辑。使用无语音的合成录音验证 10 种格式（包括短 MP3、浮点 WAV 与中文路径）；不依赖测试机器安装的第三方解码包。

已用真实引擎、真实模型和中文路径的音频跑通完整流程（识别、对齐、分行、音频读取），并用一段英文录音复验：英文按空格成词，句子在句点处换行，时间范围覆盖整段音频。回归测试覆盖时间戳换算、分行、模型登记、接口、拖放与点行播放。桌面端目前只做离屏冒烟测试，尚未在真机上人工点选；日语、韩语等其他语言的断词效果和长音频的识别耗时仍未实测。
